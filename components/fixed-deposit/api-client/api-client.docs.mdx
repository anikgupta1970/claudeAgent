## API Client

The API Client provides a clean interface for all Fixed Deposit journey API calls with built-in mock mode support for previews and testing.

### Creating a Client

```tsx
import { createApiClient } from '@api-banking/fixed-deposit.api-client';

// Real client (default)
const client = createApiClient();

// Mock client for previews
const mockClient = createApiClient({ mock: true });

// Custom configuration
const customClient = createApiClient({
  baseUrl: 'https://api.example.com',
  clientId: 'my-client-id',
  mock: false,
});
```

### Using with React Context

Wrap your app with `ApiClientProvider`:

```tsx
import { ApiClientProvider } from '@api-banking/fixed-deposit.api-client';

// For real API calls
function App() {
  return (
    <ApiClientProvider>
      <JourneyApp />
    </ApiClientProvider>
  );
}

// For mock mode (previews/compositions)
function PreviewApp() {
  return (
    <ApiClientProvider config={{ mock: true }}>
      <JourneyApp />
    </ApiClientProvider>
  );
}
```

Then use the `useApiClient` hook in components:

```tsx
import { useApiClient } from '@api-banking/fixed-deposit.api-client';

function MyComponent() {
  const api = useApiClient();

  const handleSubmit = async () => {
    const response = await api.authorize({
      acceptedTerms: [{ id: '1' }],
      credential: { type: 'mobile_dob', mobile: '9876543210', dob: '1990-01-01' },
    });

    if ('success' in response && response.success === false) {
      // Handle error
      console.error(response.errors);
    } else {
      // Handle success
      console.log('Session ID:', response.sessionId);
    }
  };

  return <button onClick={handleSubmit}>Submit</button>;
}
```

### Available Methods

#### Auth Endpoints (No Token Required)

- `getTerms()` - Fetch terms and conditions
- `authorize(data)` - Submit credentials to start OTP flow
- `exchangeToken(data)` - Exchange OTP for access token

#### Protected Endpoints (Token Required)

- `getJourneyConfig(accessToken)` - Fetch journey configuration
- `saveDepositDetails(data, accessToken)` - Save deposit details
- `saveBankDetails(data, accessToken)` - Save bank details
- `submitFD(accessToken)` - Final submission

#### Public Endpoints

- `calculateFD(data)` - Calculate FD interest and maturity

### Mock Mode

When `mock: true` is set, all API methods return predefined happy-path responses without making network requests. This is useful for:

- Component previews/compositions
- Development without a running backend
- Testing UI flows
