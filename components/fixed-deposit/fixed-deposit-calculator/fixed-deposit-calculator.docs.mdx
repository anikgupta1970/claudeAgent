import { FixedDepositCalculator, FixedDepositCalculatorBase } from './index';

## Overview

This package exports two components:

- **`FixedDepositCalculator`** (Smart) - Built-in API integration, manages calculation state internally
- **`FixedDepositCalculatorBase`** (Presentational) - Full control over calculation logic and state

## Smart Component (FixedDepositCalculator)

Use this when you want automatic API handling:

```js
<FixedDepositCalculator
  input={{
    amount: '10000',
    tenureYears: '1',
    tenureMonths: '0',
    tenureDays: '0',
    interestPayout: 'monthly',
    fdType: 'withdrawable',
  }}
  onCalculationComplete={(result) => console.log('Done:', result)}
  onCalculationError={(error) => console.error('Error:', error)}
/>
```

### API Client

The smart component uses [`@api-banking/fixed-deposit.api-client`](https://bit.cloud/api-banking/fixed-deposit/api-client) for all API requests. Authentication is handled internally by the api-client component, so you don't need to manage tokens or headers manually.

## Presentational Component (FixedDepositCalculatorBase)

Use this when you need full control over calculation logic:

```js
<FixedDepositCalculatorBase
  input={input}
  onCalculate={handleCalculate}
  result={calculationResult}
  error={calculationError}
  isCalculating={isCalculating}
  disabled={isSubmitting}
/>
```
