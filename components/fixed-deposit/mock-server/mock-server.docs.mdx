A Node.js Express server that simulates the backend API for the Fixed Deposit journey. Provides authentication, OTP verification, and journey step validation endpoints.

## Run the server

```bash
bit run api-banking.fixed-deposit/mock-server
```

The server runs on `http://localhost:3000` by default (configurable via `PORT` env variable).

## API Endpoints

### Public Endpoints

#### GET /login/terms

Fetch terms and conditions that must be accepted before login.

```bash
curl http://localhost:3000/login/terms \
  -H "Client-Id: my-client-id"
```

**Response:**
```json
{
  "terms": [
    { "id": "1", "summary": "Privacy Policy...", "documentUrl": "https://..." },
    { "id": "2", "summary": "Consent...", "content": "Full consent text..." }
  ]
}
```

#### POST /login/authorize

Validate credentials and accepted terms, initiate OTP session.

```bash
curl -X POST http://localhost:3000/login/authorize \
  -H "Content-Type: application/json" \
  -d '{
    "acceptedTerms": [{ "id": "1" }, { "id": "2" }],
    "credential": {
      "type": "mobile_dob",
      "mobile": "9876543210",
      "dob": "1990-01-15"
    }
  }'
```

**Response:**
```json
{
  "sessionId": "uuid-session-id",
  "hint": "OTP has been sent to xxxx3210",
  "expiresIn": 60,
  "maxAttempts": 3,
  "otpLength": 6
}
```

**Credential Types:**
- `mobile_dob` - Mobile + Date of Birth
- `mobile_pan` - Mobile + PAN
- `mobile_dob_pan` - Mobile + DOB + PAN
- `debit_card` - 16-digit debit card number
- `ucic_password` - UCIC (8-12 digits) + Password

#### POST /login/token

Verify OTP and exchange for access/refresh tokens.

```bash
curl -X POST http://localhost:3000/login/token \
  -H "Content-Type: application/json" \
  -d '{ "sessionId": "uuid-session-id", "otp": "123456" }'
```

**Response:**
```json
{
  "accessToken": "eyJ...",
  "refreshToken": "uuid-refresh-token",
  "tokenType": "Bearer",
  "expiresIn": 3600
}
```

### Protected Endpoints

All protected endpoints require Bearer token authentication:
```
Authorization: Bearer <accessToken>
```

#### GET /journey/config

Fetch journey configuration for the authenticated user.

```bash
curl http://localhost:3000/journey/config \
  -H "Authorization: Bearer <accessToken>"
```

**Response:** Returns `JourneyConfig` with step definitions, components, and layout.

#### PUT /api/auth/deposit

Validate and save deposit details.

```bash
curl -X PUT http://localhost:3000/api/auth/deposit \
  -H "Authorization: Bearer <accessToken>" \
  -H "Content-Type: application/json" \
  -d '{
    "fdType": "withdrawable",
    "amount": "50000",
    "interestPayout": "monthly",
    "maturityInstructions": "DO_NOT_RENEW",
    "tenureYears": "1",
    "tenureMonths": "0",
    "tenureDays": "0"
  }'
```

#### PUT /api/auth/bank

Validate and save bank details.

```bash
curl -X PUT http://localhost:3000/api/auth/bank \
  -H "Authorization: Bearer <accessToken>" \
  -H "Content-Type: application/json" \
  -d '{
    "fundingOption": "primary-bank",
    "branch": "1",
    "addNominee": true
  }'
```

#### POST /api/auth/submit

Submit the final FD application.

```bash
curl -X POST http://localhost:3000/api/auth/submit \
  -H "Authorization: Bearer <accessToken>"
```

**Response:**
```json
{
  "success": true,
  "message": "Application submitted successfully",
  "applicationId": "APP-1234567890"
}
```

## Error Response Format

All validation errors follow this format:

```json
{
  "success": false,
  "errors": [
    { "field": "amount", "message": "Minimum amount is ₹5,000" },
    { "field": "branch", "message": "Please select a branch" }
  ]
}
```

## Validation Rules

### Deposit Validation
- **Amount:** ₹5,000 - ₹1,000,000,000
- **Tenure:** 7 days - 10 years
- **At Maturity payout:** Tenure must be 7-180 days

### Bank Validation
- **Branch:** Required for Primary Bank or Combined Funds
- **Primary Amount:** Required for Combined Funds option

## Compose to Platform

