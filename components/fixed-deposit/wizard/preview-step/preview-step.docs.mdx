A read-only step in the Fixed Deposit journey that displays all collected form data (login info, deposit details, bank details) for user review before final submission.

## Basic usage

```tsx
import { PreviewStep } from '@api-banking/fixed-deposit.wizard.preview-step';

export function PreviewStepExample() {
  return (
    <PreviewStep
      onContinue={() => submitApplication()}
      onBack={() => goToBankDetails()}
    />
  );
}
```

## Data from context

The component reads form data from the journey context. No props are needed to pass data:

```tsx
// Data structure displayed from context:
{
  formData: {
    login: { ... },    // Login credentials
    deposit: { ... },  // FD type, amount, tenure, etc.
    bank: { ... }      // Funding option, branch, nominee
  }
}
```

## Integration with journey context

The component must be wrapped in `AuthenticationProvider` to access form data:

```tsx
import { AuthenticationProvider } from '@api-banking/fixed-deposit.hooks.use-journey-context';

export function JourneyIntegration() {
  return (
    <AuthenticationProvider>
      {/* Previous steps populate formData */}
      <PreviewStep
        onContinue={() => navigateToSubmit()}
        onBack={() => navigateToBankDetails()}
      />
    </AuthenticationProvider>
  );
}
```

## Display sections

The component renders three sections:
- **Login Info** - User credentials and verification data
- **Deposit Info** - FD configuration (type, amount, tenure, payout)
- **Bank Info** - Funding source, branch, nominee settings

Each section displays key-value pairs with automatic formatting of camelCase keys to readable labels.
