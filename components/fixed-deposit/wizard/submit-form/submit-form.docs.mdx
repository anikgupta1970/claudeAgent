The final step in the Fixed Deposit journey that displays a success message after the application has been submitted.

## Basic usage

```tsx
import { SubmitForm } from '@api-banking/fixed-deposit.pages.submit-form';

export function SubmitFormExample() {
  return <SubmitForm />;
}
```

## Component behavior

This is a simple confirmation component with no props. It displays:
- A success heading ("Application Submitted!")
- A confirmation message

## Usage in journey flow

Typically used after successful API submission in the journey app:

```tsx
import { SubmitForm } from '@api-banking/fixed-deposit.pages.submit-form';

export function JourneyFinalStep() {
  const [isSubmitted, setIsSubmitted] = useState(false);

  const handleSubmit = async () => {
    const response = await submitApplication();
    if (response.success) {
      setIsSubmitted(true);
    }
  };

  if (isSubmitted) {
    return <SubmitForm />;
  }

  return <PreviewStep onContinue={handleSubmit} />;
}
```

## Extended wrapper usage

In the journey app, a wrapper component handles the API submission and displays additional details:

```tsx
// Wrapper adds:
// - Auto-submission on mount
// - Loading state during API call
// - Application ID display from server response
// - Server error handling

export function SubmitFormWrapper() {
  const { formData, accessToken, serverErrors } = useJourneyContext();
  const [applicationId, setApplicationId] = useState(null);

  useEffect(() => {
    submitToServer(formData, accessToken).then((response) => {
      setApplicationId(response.applicationId);
    });
  }, []);

  return <SubmitForm applicationId={applicationId} />;
}
```
