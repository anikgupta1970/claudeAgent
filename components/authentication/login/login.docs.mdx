A comprehensive login page for API Banking that collects customer credentials (mobile, DOB, PAN, debit card, or UCIC/password) and requires acceptance of terms before proceeding.

## Basic usage

```tsx
import { Login } from '@api-banking/authentication.pages.login';

export function LoginExample() {
  const handleContinue = (data) => {
    console.log('Login data:', data);
    // data.credential contains the credentials
    // data.acceptedTerms contains accepted term IDs
  };

  return <Login onContinue={handleContinue} />;
}
```

## Credential modes

Different credential combinations for various authentication flows:

```tsx
// Mobile + DOB (default)
<Login credentials="mobile_dob" onContinue={handleContinue} />

// Mobile + PAN
<Login credentials="mobile_pan" onContinue={handleContinue} />

// Mobile + DOB + PAN
<Login credentials="mobile_dob_pan" onContinue={handleContinue} />

// Debit card only
<Login credentials="debit_card" onContinue={handleContinue} />

// UCIC + Password
<Login credentials="ucic_password" onContinue={handleContinue} />
```

## Custom terms

Provide terms fetched from your API:

```tsx
export function WithCustomTerms() {
  const [terms, setTerms] = useState([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    fetchTerms().then((data) => {
      setTerms(data.terms);
      setIsLoading(false);
    });
  }, []);

  return (
    <Login
      terms={terms}
      isLoadingTerms={isLoading}
      onContinue={handleContinue}
    />
  );
}
```

## Handling server validation errors

Display field-specific errors returned from the server:

```tsx
export function WithServerErrors() {
  const [errors, setErrors] = useState([]);
  const [isSubmitting, setIsSubmitting] = useState(false);

  const handleContinue = async (data) => {
    setIsSubmitting(true);
    const response = await loginAuthorize(data);
    if (!response.success) {
      setErrors(response.errors);
      // Example: [{ field: 'mobile', message: 'Invalid mobile number' }]
    }
    setIsSubmitting(false);
  };

  return (
    <Login
      serverErrors={errors}
      isSubmitting={isSubmitting}
      onContinue={handleContinue}
    />
  );
}
```

## Validation rules

- **Mobile:** Exactly 10 digits
- **DOB:** Required for mobile_dob and mobile_dob_pan modes
- **PAN:** Exactly 10 characters (XXXXX0000X format)
- **Debit Card:** Exactly 16 digits
- **UCIC:** 8-12 digits
- **Password:** 8-64 characters
- **Terms:** All terms must be accepted before submission
