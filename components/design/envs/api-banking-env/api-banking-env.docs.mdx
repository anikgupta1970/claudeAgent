A reusable development environment for React components within the api-banking.design scope.
It is pre-configured to seamlessly integrate and apply the 'api-banking.design/api-banking-theme', ensuring a consistent look and feel across all components.
This environment provides essential dev tooling such as TypeScript and Storybook, promoting a smooth and efficient development workflow.

Features:
- ✅ TypeScript support for writing type-safe React components.
- 🎨 Integration with 'api-banking.design/api-banking-theme' for consistent styling.
- 📚 Storybook setup for UI component development and showcasing.

## Applying the ApiBankingTheme

This environment automatically wraps your components with the `ApiBankingTheme` provider.
This ensures that all components rendered within this environment inherit the styling defined in your theme.

```tsx
function MyComponent() {
  return (
    <div>
      <h1>Welcome to ApiBanking</h1>
      <p>This component is styled with the ApiBankingTheme.</p>
    </div>
  );
}
```
## Creating a Themed Component
To create a new component that uses the `ApiBankingTheme`, simply create a new React component and render it within this environment.
```tsx
import React from 'react';
function ThemedComponent() {
  return (
    <div style={{ backgroundColor: '#f0f0f0', padding: '20px' }}>
      <h2>Themed Component</h2>
      <p>This component is styled using the ApiBankingTheme.</p>
    </div>
  );
}
```
## Previewing Components with Storybook
Storybook is configured to automatically load and display your components with the ApiBankingTheme applied.
Use Storybook stories to showcase the different states and variations of your components.
```tsx
// Button.stories.tsx
import React from 'react';
import { Button } from './Button.js';
export default {
  title: 'Button',
  component: Button,
};
const Template = (args) => <Button {...args} />;
export const Primary = Template.bind({});
Primary.args = {
  primary: true,
  label: 'Primary Button',
};
