A generic icon component for composing consistent icons across the application. It accepts basic SVG element props, `size`, `color`, and an `onClick` event handler. It supports a prop type for specific icon components to use, ensuring default size and color for icons are derived from the theme.

## Component usage

Use the component to render any SVG path:

```jsx
<Icon>
  <path d="M0 0 L10 10" />
</Icon>
```
## Sized and colored icons

  <Icon size="24px"><path d="M12 12c2.21 0 4-1.79 4-4s-1.79-4-4-4-4 1.79-4 4 1.79 4 4 4zm0 2c-2.67 0-8 1.34-8 4v2h16v-2c0-2.66-5.33-4-8-4z" /></Icon>

## Interactive icon
When an `onClick` handler is provided, the icon becomes interactive with hover effects:
```jsx
<Icon size="32px" onClick={() => alert('Close icon clicked!')}>
  <path d="M19 6.41L17.59 5 12 10.59 6.41 5 5 6.41 10.59 12 5 17.59 6.41 19 12 13.41 17.59 19 19 17.59 13.41 12z" />
</Icon>
```
