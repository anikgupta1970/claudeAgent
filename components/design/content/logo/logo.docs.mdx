A versatile and brand-conscious logo component tailored for 'API Banking', with the ability to adapt to diverse presentation needs.

## Component usage

Use the component to display the brand logo and name, with optional slogan and customization.

```js
<Logo name="Your Bank" slogan="The future of banking" />
```
## Logo Variations
Different ways to display the logo, including a minimal version with just the icon, a custom size, and a slogan.
```js
<Flex gap="4">
  <Logo slogan="Secure. Fast. Connected." />
  <Logo minimal logoSize={30} />
  <Logo logoSize={50} slogan="Scaling new heights" />
</Flex>
```
## Custom Logo
Override the default logo with a custom image or SVG, allowing for complete branding control.
```js
<Logo
  logo={<img src="your-custom-logo.svg" alt="Custom Logo" style={{ width: '40px', height: '40px' }} />}
  name="Custom Brand"
  slogan="Innovation in finance"
  logoSize={40}
/>
