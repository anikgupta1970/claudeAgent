The Card component can be configured with distinct header and footer sections, and supports multiple visual styles with a modern, clean aesthetic.

## Component usage

Use the component to wrap content in a card.

```js
<Card>
  <div>Some Content</div>
</Card>
```
## Card with header and footer
Cards can have headers and footers.
The header is at the top, and the footer is at the bottom.
```js
<Card
  header={<div>Header Content</div>}
  footer={<div>Footer Content</div>}
>
  <div>Main Content</div>
</Card>
```
## Interactive Outlined Card
This example shows an interactive card with an outlined style.
Hovering over the card will show an effect.
```js
<Card interactive variant="outlined">
  <div>Interactive Outlined Card</div>
</Card>
