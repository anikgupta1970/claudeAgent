The `Link` component is designed for seamless navigation, supporting both internal routing via React Router DOM and external links.

## Component Usage

This component adapts its behavior based on the `href` and `external` properties, rendering either a `<Link>` (React Router) or an `<a>` (standard HTML) element.

```js
<Link href="/home">Home</Link>
```
## External Link Example
To create a link that opens in a new tab, set `external` to true and specify `target="_blank"`.
```js
<Link href="https://example.com" external target="_blank">
  Visit Example.com
</Link>
```
## Disabled Link Example
The `disabled` prop prevents interaction with the link, rendering it in a disabled state.
```js
<Link href="/some-route" disabled>
  Disabled Link
</Link>
