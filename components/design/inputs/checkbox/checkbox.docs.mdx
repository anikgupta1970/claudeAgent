A custom checkbox component with accessible and theme-aligned styling, providing distinct visual states for checked, unchecked, and disabled scenarios.

## Component usage

Use the component:

```js
<Checkbox id="terms" label="Accept Terms" />
```

## Checkbox States
This example showcases the different states of the Checkbox component, including default, checked, and disabled states.

```js
<Checkbox id="default-unchecked" label="Default Unchecked" />
<Checkbox id="default-checked" checked label="Default Checked" />
<Checkbox id="disabled-unchecked" disabled label="Disabled Unchecked" />
<Checkbox id="disabled-checked" checked disabled label="Disabled Checked" />
```

## Interactive Consent Checkboxes
Demonstrates the Checkbox component being used to capture user consent, with the state of each checkbox managed interactively.

```js
function InteractiveConsent() {
  const [isPolicyAccepted, setPolicyAccepted] = React.useState(false);
  const [isProductsConsented, setProductsConsented] = React.useState(false);
  return (
    <>
      <Checkbox
        id="privacy-policy"
        checked={isPolicyAccepted}
        onChange={(e) => setPolicyAccepted(e.target.checked)}
        label="I/we have read, understood, and hereby accept the Privacy Policy of the bank."
      />
      <Checkbox
        id="requested-products"
        checked={isProductsConsented}
        onChange={(e) => setProductsConsented(e.target.checked)}
        label="I/we hereby give consent (V.1.0) in relation to Requested Products"
      />
    </>
  );
}
<InteractiveConsent />
```

## Checkbox with Rich Label
An example of using a more complex React node as the label for the Checkbox, including a link that opens Terms and Conditions.

```js
function CheckboxWithLink() {
  const [isChecked, setIsChecked] = React.useState(false);
  const handleLinkClick = (e) => {
    e.stopPropagation();
    alert('Navigating to Terms and Conditions...');
  };
  return (
    <Checkbox
      id="terms-agreement"
      checked={isChecked}
      onChange={() => setIsChecked(!isChecked)}
      label={
        <span>
          I agree to the{' '}
          <a
            href="#"
            onClick={handleLinkClick}
            style={{
              color: 'var(--colors-text-primary)',
              textDecoration: 'underline',
            }}
          >
            Terms and Conditions
          </a>
          .
        </span>
      }
    />
  );
}
<CheckboxWithLink />
