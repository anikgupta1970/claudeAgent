A foundational text input component for various form fields.
It supports adornments, different states, and is styled according to the theme.

## Component usage

Use the component in your forms

```js
<TextInput
  id="name"
  value={value}
  onChange={handleChange}
  placeholder="Enter your name"
/>
```

## Basic Text Input
A simple text input field for collecting user input.
```js
<TextInput
  id="basic-input"
  value="Some value"
  onChange={() => {}}
  placeholder="Enter text"
/>
```

## Input with Different States
Showcasing different states of the input field, such as error, disabled, and password.
```js
<TextInput
  id="error-input"
  value="Error value"
  onChange={() => {}}
  placeholder="Error state"
  error
/>
<TextInput
  id="disabled-input"
  value="Cannot be edited"
  onChange={() => {}}
  placeholder="Disabled"
  disabled
/>
<TextInput
  id="password-input"
  value="password123"
  onChange={() => {}}
  type="password"
  placeholder="Password"
/>
```
