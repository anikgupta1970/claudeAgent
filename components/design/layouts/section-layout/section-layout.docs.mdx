The SectionLayout component elevates content presentation with optional title, caption, and subtitle.

## Component usage

Use the component to structure page content:

```jsx
<SectionLayout
  title="Section Title"
  subtitle="A brief description"
  caption="Additional details"
>
  <div>Section Content</div>
</SectionLayout>
```

## Basic Section Layout
A simple section layout with a title and content.
It is suitable for grouping related information on a page.
```jsx
<SectionLayout title="Customer Details">
  <div>Customer information form or details go here.</div>
</SectionLayout>
```

## Section Layout with Full Header
Demonstrates the use of title, subtitle, and caption to provide a complete header for the section.
This is useful when you need to provide additional context and information about the section.
```jsx
<SectionLayout
  title="Consent & Conditions"
  subtitle="Please review and accept the following terms to continue."
  caption="For full details read our Terms and Conditions and Privacy Policy."
>
  <div>Consent checkboxes and related content.</div>
</SectionLayout>
```

## Section Layout with Rich Content
Showcases how to include rich content such as images within a section layout.
This can enhance the visual appeal and engagement of the section.
```jsx
<SectionLayout
  title="Welcome to Secure Banking"
  subtitle="Your financial safety is our top priority."
>
  <img
    src="image-url.jpg"
    alt="Secure banking illustration"
    style={{ width: '100%', borderRadius: '8px', marginTop: '16px' }}
  />
  <div>Additional content related to secure banking.</div>
</SectionLayout>
