A responsive page layout component that wraps the main content, sets the page title, and injects SEO meta tags.

## Component usage

Use the component to wrap the main content of your pages, ensuring consistent styling and SEO optimization

```jsx
<PageLayout title="My Page Title" description="Page description" keywords="keyword1, keyword2">
  <div>Your page content here</div>
</PageLayout>
```
## Basic Page Layout
This example demonstrates the basic usage of the `PageLayout` component with a title, description, and some content.
```jsx
<PageLayout title="Basic Page" description="A simple page layout example.">
  <div>
    <h1>Welcome!</h1>
    <p>This is a basic page layout.</p>
  </div>
</PageLayout>
```
## Login Page Example
This example showcases a more complex usage, creating a login page layout with form elements.
```jsx
<PageLayout
  title="Login Page"
  description="Login to access your account."
  keywords="login, account"
>
  <form>
    <label>Username:</label>
    <input type="text" />
    <label>Password:</label>
    <input type="password" />
    <button type="submit">Login</button>
  </form>
</PageLayout>
```
## Themed Content
You can also use the component to render themed content using API Banking Theme.
```jsx
<ApiBankingTheme>
  <PageLayout
    title="Themed Page"
    description="A page with themed content."
    keywords="theme, styled"
  >
    <div style={{ backgroundColor: 'var(--colors-surface-primary)', padding: 'var(--spacing-large)' }}>
      <h1>Themed Content</h1>
      <p>This page has a themed background.</p>
    </div>
  </PageLayout>
</ApiBankingTheme>
