A versatile and accessible paragraph component that prioritizes readability and consistent typography.
It uses theme-based styles for a consistent look and feel across the application.

## Component usage

Use the component:

```js
<Paragraph>
  This is a paragraph.
</Paragraph>
```

## Basic Paragraphs
Displays standard paragraphs with default styling.
```js
<ApiBankingTheme>
  <div>
    <Paragraph>
      I/we have read, understood, and hereby accept the Privacy Policy.
    </Paragraph>
    <Paragraph>OTP has been sent to xxxx3210</Paragraph>
  </div>
</ApiBankingTheme>
```

## Lead Paragraphs
Demonstrates paragraphs with a lead variant for emphasizing text.
```js
<ApiBankingTheme>
  <div>
    <Paragraph variant="lead">Login</Paragraph>
    <Paragraph variant="lead">Customer Details</Paragraph>
    <Paragraph variant="lead">Enter OTP</Paragraph>
  </div>
</ApiBankingTheme>
```

## Muted Paragraphs
Shows paragraphs with a muted variant for displaying less prominent information.
```js
<ApiBankingTheme>
  <div>
    <Paragraph variant="muted">
      For testing purposes Mobile Number: 9876543210
    </Paragraph>
    <Paragraph variant="muted">
      For testing purposes, please use OTP: 123456
    </Paragraph>
    <Paragraph variant="muted">
      For full details read our Terms and Conditions and Privacy Policy.
    </Paragraph>
  </div>
</ApiBankingTheme>
