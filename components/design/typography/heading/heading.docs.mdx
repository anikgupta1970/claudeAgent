A semantic and visually consistent heading component that enhances content structure and readability.

## Component usage

Use the component to add a heading to your content:

```jsx
<Heading level={1}>Main Title</Heading>
```
### All Heading Levels
This example demonstrates all the available heading levels, from `h1` to `h6`.
```jsx
<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--spacing-medium)' }}>
  <Heading level={1}>Heading 1</Heading>
  
  <Heading level={2}>Heading 2</Heading>
  
  <Heading level={3}>Heading 3</Heading>
  
  <Heading level={4}>Heading 4</Heading>
  
  <Heading level={5}>Heading 5</Heading>
  
  <Heading level={6}>Heading 6</Heading>
</div>
```
### Visual Level Override
This example shows how to use the `visualLevel` prop to apply visual styles independent of the semantic level.
```jsx
<div>
  <Heading level={1} visualLevel="h3">
    Page Title (H1 Tag, H3 Style)
  </Heading>
  
  <Heading level={3}>
    Section Title (H3 Tag, H3 Style)
  </Heading>
</div>
```
### Inverse Color Heading
This example demonstrates how to use the `inverseColor` prop for high contrast and readability on dark backgrounds.
```jsx
<div
  style={{
    backgroundColor: 'var(--colors-primary-default)',
    padding: 'var(--spacing-xl)',
    borderRadius: 'var(--borders-radius-large)',
    maxWidth: '600px',
  }}
>
  <Heading level={2} inverseColor>
    Enter OTP
  </Heading>
  
</div>
